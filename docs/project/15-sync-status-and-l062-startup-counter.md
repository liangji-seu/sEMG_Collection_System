# 同步状态与 L062 首帧计数边界（2026-10-09）

## 同步完成与对齐验证分别记录

此前 `sync_status_summary` 要求所有 IMU 时间对齐严格验证后才显示 `synced`，但现有 IMU 对齐是启发式方法，始终保留 `unverified` 置信度。因此 EMG ADC 校验通过且数据写入完成，也会显示整份文件 `unverified`。

现在 `synced` 表示所有必需物理设备的 EMG 校验、来源记录和非空输出齐全，且存在物理 IMU 时，其必需 100 Hz 输出与处理证据齐全。按用户要求，界面统一显示“已同步”，不展示 IMU 对齐方式或待验证说明。内部审计属性保留。

缺少必需设备或 IMU 输出仍是 `partial`；关闭 ADC 校验、缺少逐设备验证证据的旧结果仍是 `unverified`。读取已有完整结果时按证据计算状态，无需为了更换状态重新生成数据。

重复同步跳过整个设备时保留其 IMU 证据；重新生成 EMG 但缺少本轮 IMU 输入时，旧 IMU 输出不能作为本轮完成的证据。GUI 暂缓发布总状态时仍写入同步方式、偏移和逐设备历史，预览使用相同的状态判定。

一对一同步以各自配对 bin 的实际记录为输出主体：EMG 与 IMU 都完整保存，IMU 不再因缺少 BLE 锚点而按 EMG 范围裁掉首尾。输出保留物理零值，不按活跃度删除传感器，也不为 bin 中不存在的记录添加虚构样本。IMU 数据集记录来源帧数、输出帧数与 `sync_full_bin_preserved`。旧 IMU 结果若没有全量记录，会允许重新同步升级；一对多原有会话范围保持原样。

## 有界恢复规则

只对已开启 ADC 校验的一对一同步允许恢复“孤立非零首条 → 0 → 连续递增”的明确结构。原始解析器默认仍拒绝重复、重置和回绕；中途重置、后续缺口或重新排序不在本次恢复范围内。

恢复保留全部原始样本和记录顺序，不删除首条，不替换 ADC，不覆盖重复原始帧号。输出以 `source_bin_row` 定位原 bin 的物理记录，以 `raw_sd_frame_id` 保存原始计数器；逻辑时间轴使用独立坐标。偏移作用域和分段来源记录明确说明其坐标含义，不把逻辑编号称为原始帧号。孤立首条时间按记录顺序外推并记录其推定性质。

写入前还必须通过逐采样 ADC 强匹配；仅相关性匹配不允许进入本恢复路径。正常计数器的 bin、一对多和多 bin rescue 保持原有契约。
